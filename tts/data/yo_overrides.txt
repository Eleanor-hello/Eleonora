# Персональные override-формы для yoficator.
# Те же правила что и в yo_safe.txt — основа [+ (суф1|суф2|...)].
# Первая пустая альтернатива в скобках = форма без суффикса.
#
# Зачем: eyo-kernel не включает уменьшительные имена (Серёжа, Жужа),
# современный сленг и личные имена проекта.
# Override-файл подгружается ПОСЛЕ safe.txt → перекрывает конфликты.

# ── имена проекта ──
Серёж(|а|е|ей|ею|и|у)
Серёжин(|а|е|ой|у|ы|ым|ыми|ых|о|ого|ом|ому|ую)
# «Жужа» — ё нет, но держим комментарий чтобы не было соблазна добавить

# ── патчи багов eyo-kernel safe.txt ──
# В safe.txt у «полёт» строка «полёт(а|ам|ами|ах|ов|ом|у|ы)» — без пустой
# альтернативы. Значит лемма «полёт» (имен. падеж) не производится, только
# косвенные. Для «самолёт» у них есть отдельная строка «самол(ёт|ёте)»,
# для «полёт» — забыли. Добавляем вручную.
полёт
