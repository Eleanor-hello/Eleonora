# Eleonora v3

Eleonora — интеллектуальный голосовой ИИ-компаньон с адаптивной памятью, контролем ударений и естественной речью.

## Возможности

- **Интерактивный чат**: Диалог с Элеонорой в фирменной тёмной неоновой теме (#0B0B16, #131324, #1A1A3E, #8B5CF6).
- **Управление сессиями диалогов**: Создание новых диалогов (➕), просмотр истории и переключение между ними (📜), удаление старых сессий.
- **Агент ударений (Stress Check Agent)**: Автоматическое распознавание и обучение ударениям из сообщений пользователя (например: `молок+о` или `не звОнит, а звонИт`). Моментальный отклик и сохранение в базу ударений.
- **Агент памяти (Memory Agent & Consolidator)**: Консолидация фактов о пользователе (имя, питомцы, профессия, увлечения) и поиск релевантных воспоминаний при генерации ответов.
- **Озвучка (TTS)**: Воспроизведение ответов голосом с предварительной очисткой (санитизацией) от markdown, ссылок и эмодзи, а также ёфикацией и расстановкой ударений.
- **Панель логов (Agent Telemetry Log Panel)**: Док-панель для просмотра работы агентов (`[stress_check]`, `[search_check]`, `[memory]`, `[llm]`, `[chat]`) в реальном времени.

## Запуск

```bash
npm install
npm run dev
```

Приложение запускается на порту `3000`.
